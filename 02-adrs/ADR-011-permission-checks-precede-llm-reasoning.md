# ADR-011 — Permission checks precede LLM reasoning

- **Status:** Accepted
- **Scope:** product
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Evidence/permission checks precede LLM reasoning.

## Rationale / consequence

Unauthorized evidence must never enter the model context.
