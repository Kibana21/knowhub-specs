# ADR-002 — Application is the primary enterprise scope

- **Status:** Accepted
- **Scope:** product
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Application is the primary enterprise scope, not repository.

## Rationale / consequence

An application can contain multiple repos, Jira projects, docs, APIs, data and runtime sources.
