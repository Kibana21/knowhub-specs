# ADR-010 — Human documentation and agent context are separate

- **Status:** Accepted
- **Scope:** product
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Human documentation and machine agent context are separate artifacts.

## Rationale / consequence

Different audiences, size constraints and refresh behavior.
