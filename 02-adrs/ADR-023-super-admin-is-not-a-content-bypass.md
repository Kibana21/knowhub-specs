# ADR-023 — Platform Super Admin is not a content bypass

- **Status:** Accepted
- **Scope:** product
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

Platform Super Admin is not a universal evidence-content bypass.

## Rationale / consequence

Administrative power remains least privilege; emergency content access, if required, uses separate audited time-limited break-glass entitlement.
