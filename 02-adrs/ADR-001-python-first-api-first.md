# ADR-001 — KnowHub is Python-first and API-first

- **Status:** Accepted
- **Scope:** product
- **Origin:** master blueprint §82
- **Supersedes:** —
- **Superseded by:** —

## Decision

KnowHub is Python-first, API-first; do not port Rust/Tauri packaging.

## Rationale / consequence

Preserve behavior, simplify enterprise deployment and use the team's Python ecosystem.
